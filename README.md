
   
AI Voice Ordering Chatbot is a full-stack AI-powered ordering system designed for restaurants. The application allows customers to place orders completely through voice interaction. The system converts customer speech into text, processes the conversation using AI models, responds naturally with AI-generated voice, and automatically generates digital receipts.

The project combines modern AI technologies with scalable web development frameworks to create an interactive and intelligent customer ordering experience.

Real-time voice ordering system

AI-powered conversational chatbot
Natural AI voice responses using ElevenLabs
Order confirmation and receipt generation
Menu item recognition and order tracking
Fast and responsive user interface
Secure API integration using environment variables
Scalable frontend and backend architecture
